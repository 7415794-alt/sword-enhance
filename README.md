# 검 강화하기

무기를 강화하고, 강화한 무기를 팔아 골드를 버는 모바일 게임입니다. 웹(HTML/JS)으로 만들고 Capacitor로 감싸 안드로이드 앱으로 빌드합니다.

## 게임 규칙

- **강화**: 골드를 내고 강화를 시도합니다. 결과는 4가지입니다.
  | 결과 | 효과 |
  |---|---|
  | 대성공 | +2단계 |
  | 성공 | +1단계 |
  | 유지 | 변화 없음 |
  | 파괴 | 검이 부서지고 +0 검으로 돌아감 · 검 조각 획득 |
- 최대 단계는 **+300**입니다. 단계가 오를수록 성공 확률은 내려가고 파괴 확률은 올라갑니다.
  | 단계 | 성공(대성공 포함) | 파괴 |
  |---|---|---|
  | +0 | 95% | 0% |
  | +10 | 74% | 2.9% |
  | +30 | 45% | 10% |
  | +50 | 27% | 18% |
  | +100 | 8% | 25% |
  | +130 ~ +299 | 4% | 25% |
- 단계에 따라 이름 앞에 붙는 말과 색이 21가지로 바뀝니다 (녹슨 → 무쇠 → … → 창세의 → +300 절대신의).
- **무기 10종**: 판매하거나 파괴되면 새 무기가 무작위로 나옵니다.
  | 무기 | 등급 | 확률 | 특징 |
  |---|---|---|---|
  | 나뭇가지 | 흔함 | 22% | 성공 +8%p · 판매가 ×0.6 |
  | 목검 | 흔함 | 18% | 파괴 -20% · 판매가 ×0.8 |
  | 단검 | 보통 | 15% | 대성공 2배 · 판매가 ×0.9 |
  | 장검 | 보통 | 14% | 기본 |
  | 도끼 | 보통 | 10% | 파괴 시 조각 2배 · 판매가 ×1.1 |
  | 창 | 희귀 | 8% | 성공 +2%p · 판매가 ×1.3 |
  | 대검 | 희귀 | 6% | 파괴 -30% · 판매가 ×1.5 |
  | 카타나 | 영웅 | 4% | 대성공 2배 · 판매가 ×1.8 |
  | 사신의 낫 | 전설 | 2% | 파괴 +25% · 판매가 ×3 |
  | 황금 검 | 신화 | 1% | 판매가 ×5 · 조각 3배 |
- **자동 강화**: 목표 단계, 배속(1~128배, 1배 = 초당 약 2.6회), 목표 도달 시(판매·보관 후 반복/멈춤), 파괴 시(계속/멈춤), 사용할 아이템(떨어지면 자동 구매)을 정해 자동으로 강화합니다.
- **판매**: 현재 무기를 팔아 골드를 받고 새 +0 무기를 받습니다. 판매가는 그 단계까지 올리는 평균 비용의 1.4배(+1) ~ 4.4배(+300)라서, 높이 올려 팔수록 이득입니다.
- **보조 아이템**: 강화 화면에서 켜 두면 다음 강화마다 쓰입니다. **가진 아이템 → 🔩 검 조각 → 💰 골드** 순서로 자동 결제합니다.
  골드 결제는 **지금 단계 강화 비용에 비례**합니다 (미리 살 필요 없음, 어느 단계를 파밍해도 비용이 맞음).
  강화 화면의 **⚖️ 이득일 때만 사용** 스위치를 켜면 손해인 아이템은 켜 두어도 쓰지 않습니다 (직접 · 자동 강화 공용).
  - 🛡️ 파괴 방지권: 파괴 결과가 나오면 유지로 바뀜 · 골드 결제 = 강화 비용 × 3 (파괴 확률 0%면 쓰지 않음)
  - 🍀 행운의 부적: 성공 확률 +10%p (원래 확률의 2배까지) · 강화 비용 × 2
  - ✨ 축복 주문서: 대성공 확률 3배 · 강화 비용 × 1.5
  - 검 조각으로 교환해 둘 수 있음
- **도감**: 무기 도감 10종(1종당 판매가 +2%), 강화 도감 300칸(1칸당 판매가 +1%)
- **업적**: 82종 (강화·기록·결과·파괴·판매·무기·기타·대장간). 달성하면 골드·아이템 보상, 모두 받기 가능
- **기록**: 이 기기의 최고 판매 TOP 10과 통계 (온라인 랭킹은 서버가 필요해 아직 없음)

- **보관함 · 사냥**: 강화 화면의 **보관**으로 무기를 보관함에 넣으면(기본 10칸, 무기 창고 확장으로 최대 60칸) **모두 사냥**에 나가 공격력만큼 초당 골드를 벌어 옵니다.
  공격력 = 판매가 × 무기 공격력 배율 ÷ 180, 공격력 1당 초당 0.03골드 (무기 1개가 약 100분에 판매가만큼). 오프라인 보상에도 포함됩니다.
  무기 공격력 배율: 나뭇가지 0.5 · 목검 0.6 · 단검 0.9 · 장검 1 · 도끼 1.3 · 창 1.4 · 대검 1.7 · 카타나 2 · 사신의 낫 2.6 · 황금 검 1.2
  보관함이 가득 찬 상태에서 강화 중인 무기가 가장 약한 보관 무기보다 공격력이 높아지면 **목표 단계 전이라도 바로 맞바꿉니다**
  (지금 무기는 보관 · 사냥, 약한 무기를 꺼내 이어서 강화, 아무것도 팔지 않음). 자동 강화 설정에서 끌 수 있고 직접 강화에도 적용됩니다.
  목표에 도달해 보관할 때 가득 차 있으면, 가장 약한 무기보다 강할 때만 교체(약한 무기는 판매)하고 아니면 판매합니다.
- **자동 강화 아이템 규칙 (이득일 때만 사용)**: 방지권은 '파괴 확률 × 부서지면 다시 올리는 평균 비용'이 방지권 값보다 클 때만,
  부적 · 주문서는 줄어드는 시도 비용이 아이템 값보다 클 때만 씁니다. '다시 올리는 평균 비용'은 단계마다 방지권을 쓸지 말지 더 싼 쪽을 고른다고 보고 계산합니다.
  기록 도전 중(목표 > 최고 기록)에는 파괴 위험이 있으면 방지권을 아끼지 않습니다. 강화 화면 아이템에도 이득/손해가 표시됩니다.
- **대장간 업그레이드**: 골드로 영구 능력 8종 구매 (보관함 칸, 성공 확률, 파괴 감소, 대성공, 판매가, 강화 비용, 조각, 오프라인 보상 시간)
- **환생**: 최고 기록 +100부터 가능. 환생석(+300이면 21개) 1개당 판매가 +10%, 강화 비용 -1%(최대 -50%), 시작 골드 +1만
- **오프라인 보상**: 앱을 끈 동안 시간당 골드 (기본 최대 2시간, 견습생 고용으로 +10시간)
- **무작위 이벤트**: 3~6분마다 행운의 시간 · 대성공 축제 · 수호의 시간 · 귀족 손님 · 떠돌이 상인 · 화로 대청소 · 보물 상자
- **온라인 랭킹**: Firebase Firestore (아래 설정 필요). 점수 = 누적 환생석 × 1000 + 현재 최고 기록
- 골드가 바닥나도 +0 무기는 무료로 강화할 수 있어 막히지 않습니다.

진행 상황은 기기에 자동 저장됩니다 (localStorage).

## 온라인 랭킹 연결 (Firebase)

1. https://console.firebase.google.com 에서 프로젝트 만들기 (Google 애널리틱스는 꺼도 됨)
2. 빌드 → **Firestore Database** → 데이터베이스 만들기 → 프로덕션 모드
3. Firestore → **규칙** 탭에 저장소의 `firestore.rules` 내용을 붙여 넣고 게시
4. 프로젝트 설정(⚙️) → 일반 → 내 앱 → 웹 앱(`</>`) 추가 → 표시되는 `projectId`, `apiKey` 확인
5. `www/js/config.js`에 두 값을 적고 푸시

웹 API 키는 비밀 값이 아니라 공개되어도 되는 식별자이고, 쓰기 권한은 `firestore.rules`로 제한됩니다.

## 구조

```
app-shell/           앱 실행기 (APK에 들어감, 웹사이트의 게임을 불러옴)
www/                 게임 본체 (웹사이트로 배포)
  index.html
  css/style.css
  js/data.js         밸런스 수치 · 확률표 · 아이템 · 업적 (VERSION 도 여기)
  js/game.js         강화 · 판매 · 구매 · 업적 규칙
  js/state.js        저장 · 불러오기
  js/main.js         화면 렌더링 · 이벤트 처리
  js/online.js       온라인 랭킹 (Firestore REST)
  js/config.js       랭킹 서버 설정 (Firebase 프로젝트 ID · API 키)
  js/weapon.js       무기 10종 그림 (SVG)
  js/sound.js        효과음
tools/sim.js         밸런스 시뮬레이터 (npm run sim, UPG=1 이면 업그레이드 구매 포함)
firestore.rules      온라인 랭킹 보안 규칙
tools/make-icons.js  icon.svg → PNG 아이콘 (npm run icons)
tools/android/       APK 서명 키 · 아이콘 배경
.github/workflows/   안드로이드 APK 빌드 · GitHub Pages 배포
```

## 실행

```bash
npm start            # http://localhost:8080 에서 브라우저로 실행
npm run sim          # 목표 단계별 수익 · 처음부터 +300까지 걸리는 시도 횟수 (직접 / 자동 강화)
```

## 안드로이드 앱

앱은 **실행기(`app-shell/`)** 만 들어 있고, 게임 본체는 웹사이트(https://stocksignals.kr/sword-enhance/)에서 불러옵니다.
그래서 `www/`를 수정해 `main`에 푸시하면 **앱을 다시 받지 않아도** 다음 실행 때 자동으로 최신 버전이 됩니다.
한 번 접속한 뒤에는 서비스 워커가 게임을 저장해 두어 인터넷 없이도 실행됩니다.
이전 버전 앱(게임이 앱 안에 들어 있던 버전)의 저장 데이터는 첫 실행 때 자동으로 옮겨집니다.

`app-shell/`, `capacitor.config.json`, 아이콘이 바뀔 때만 GitHub Actions가 APK를 다시 빌드해 `android-latest` 릴리스에 올립니다.
웹사이트 주소가 바뀌면 `app-shell/index.html`의 `GAME_URL`과 `capacitor.config.json`의 `allowNavigation`을 함께 고쳐야 합니다.

다운로드: `https://github.com/7415794-alt/sword-enhance/releases/download/android-latest/sword-enhance.apk`

서명 키가 고정되어 있어 새 APK를 덮어 설치해도 저장 데이터가 유지됩니다.
게임 버전을 올릴 때는 `www/js/data.js`의 `VERSION`과 `www/sw.js`의 `CACHE`를 함께 바꿉니다.
